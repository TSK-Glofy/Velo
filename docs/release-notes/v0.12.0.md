# Velo v0.12.0

## 中文

### 🐛 修复

- **拖动时间轴滑块时手柄被"吸"在鼠标上**：在视频截取 / 视频转 GIF / 逐帧提取页面拖动起始或结束手柄时，只要鼠标向下移出时间轴，WebView 就会把这次拖动当成文本选择手势接管过去。系统随即发出 `pointercancel` 并静默收回指针捕获，而组件没有处理这个事件，拖动状态就永久卡住了——之后鼠标只要（不按键）掠过时间轴，手柄就会立刻跳到光标位置并一路跟随 X 轴。现在时间轴禁止文本选择，按下时阻止默认手势，并在 `pointerup` / `pointercancel` / `lostpointercapture` 三种结束路径上都会复位拖动状态；即使捕获仍以其他方式丢失，未按下按键的移动也不会再拖动手柄。

---

## English

### 🐛 Fixes

- **Timeline handles stuck to the cursor while dragging**: on the Trim / GIF / Frame Extraction pages, dragging a start or end handle downwards off the timeline made the WebView claim the gesture as a native text selection. It then fired `pointercancel` and silently revoked our pointer capture — and because that event was never handled, the drag state stayed latched forever, so any later hover over the timeline snapped a handle to the cursor and had it follow the X axis. The timeline now blocks text selection, prevents the default gesture on pointer down, and resets the drag state on `pointerup`, `pointercancel` and `lostpointercapture` alike; a move with no button held can no longer drag a handle even if capture is lost some other way.
