# Velo v0.11.0

## 中文

### ✨ 新功能

**视频转 GIF**
- 侧边栏新增「视频转 GIF」页面，选择视频、框选时间段，一键生成 GIF
- 可调帧率（5–25 fps，默认 10）和输出宽度（320–800px 或原始宽度，默认 480px）
- 采用 FFmpeg 两阶段调色板（palettegen/paletteuse）编码，色彩质量远好于普通转换

**拖拽选择剪辑范围 + 实时画面预览**
- 视频截取、视频转 GIF、逐帧提取三个页面都新增了时间轴：拖动两侧手柄即可框选起始/结束位置，画面实时跟随
- 起始时间和持续时间输入框与时间轴双向同步——拖完自动填好，手动输入也会同步滑块
- mp4 / webm / mkv 等格式即时预览（系统 WebView 原生解码，安装包体积零增加）；AVI / FLV / WMV 等格式自动降级为 FFmpeg 抽帧预览
- 预览画面大小可在 25% / 50% / 75% / 100% 之间切换，选择会被记住

**时间输入规范化**
- 起始/持续时间输入框现在接受秒数（`90`）、分:秒（`1:30`）或 时:分:秒（`00:01:30`），失焦后自动统一为 `HH:MM:SS` 格式，支持小数秒
- 无效输入会标红并阻止创建任务

### 🐛 修复

- **任务预览图错位**：起始时间（-ss）不为 0 时，任务列表预览图总是显示视频开头附近的画面。现在预览会正确加上起始偏移，显示实际正在处理的位置

## English

### ✨ New Features

**Video to GIF**
- New "Video to GIF" page in the sidebar: pick a video, select a time range, convert in one click
- Adjustable frame rate (5–25 fps, default 10) and output width (320–800px or original, default 480px)
- Uses FFmpeg's two-stage palette encoding (palettegen/paletteuse) for far better colors than a plain conversion

**Drag-to-select trim range with live preview**
- Trim, GIF, and Frame Extraction pages all get a timeline: drag the two handles to pick start/end while the frame preview follows in real time
- The start/duration inputs stay in two-way sync with the timeline — drag to fill them, or type to move the handles
- mp4 / webm / mkv preview instantly via the system WebView's native decoder (zero installer size impact); AVI / FLV / WMV fall back to FFmpeg frame extraction automatically
- Preview size is switchable between 25% / 50% / 75% / 100%, and the choice is remembered

**Time input normalization**
- Start/duration fields accept seconds (`90`), MM:SS (`1:30`), or HH:MM:SS (`00:01:30`) and normalize to `HH:MM:SS` on blur, with sub-second precision
- Invalid input is highlighted and blocks task creation

### 🐛 Fixes

- **Task preview showed the wrong frame**: with a non-zero start time (-ss), the task list preview always showed frames from near the beginning of the source. The preview now adds the start offset back and shows the position actually being processed
